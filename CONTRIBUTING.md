# Contributing to WithoutSky

Thank you for your interest in improving WithoutSky!

## How to contribute

- Report bugs and unexpected behavior through GitHub Issues.
- Suggest features and improvements through GitHub Issues.
- Submit changes through Pull Requests.
- Explain what your change does and how you tested it.

## Contribution terms

By submitting a Pull Request, you confirm that you have the right to contribute the submitted code and that it does not knowingly infringe third-party rights.

You grant the WithoutSky project author permission to review, modify, incorporate, maintain, distribute, and license accepted contributions as part of the project.

You retain ownership of your contributions. The project author does not automatically receive ownership of your work.

Contributions are subject to the project's LICENSE file.

## Review process

All contributions are reviewed before being merged. Submission does not guarantee acceptance.

Thank you for helping make WithoutSky better!
